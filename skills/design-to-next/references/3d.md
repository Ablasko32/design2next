# 3D (three.js)

Read only when design has a 3D scene / WebGL canvas, or user asks. Never by default.

SKILL.md rules still apply. Goal: 3D never blocks the main thread, never hurts LCP.

## 1. Rules

- **three.js** (`three`), plain. React Three Fiber only if user asks (it renders on the main thread; worker setup differs, check its docs).
- **Render in a Web Worker** with `OffscreenCanvas`: scene, render loop, model loading, physics all off the main thread. Main thread only forwards size, pointer, visibility.
- **Poster is always the fallback** and the first paint: a still image of the scene (`next/image`, in `IMAGES`, WebP). Canvas fades in over it only after the worker's first frame. No support, WebGL error, reduced motion → poster stays. Poster not in design → render one frame and save it as poster, listed for user.
- Canvas is **decoration, not LCP**: hero text / poster paint first.
- Leaf `"use client"` component owns the `<canvas>`. Section stays a Server Component.
- No `OffscreenCanvas` / `transferControlToOffscreen` → poster. Interactive main-thread fallback (same `scene.ts`) only if user asks. Check current support.
- **Strict Mode safe:** dev mounts effects twice and a canvas can be transferred to a worker **once** → create the `<canvas>` inside the effect, remove it in cleanup (never `transferControlToOffscreen` on a React-rendered canvas).
- `prefers-reduced-motion` → poster (or one still frame), no loop.
- Pause when off screen (`IntersectionObserver`) or tab hidden (`visibilitychange`).
- `devicePixelRatio` capped: 2 desktop, 1.5 small / touch screens. `antialias` only if needed.
- Models: `.glb` with Draco / Meshopt compression, textures KTX2 / WebP, in `public/models/` (fixed URL, loaded by worker `fetch`). Size budget listed in summary.
- Dispose geometry, materials, textures and renderer on unmount; terminate worker.

## 2. Files

```
components/three/
  scene-canvas.tsx      "use client": poster + canvas made in effect, worker, resize / pointer / visibility
lib/three/
  scene.worker.ts       worker entry: receives OffscreenCanvas, runs render loop
  scene.ts              build scene (shared by worker and main-thread fallback)
public/models/          .glb files
assets/images/three/    poster.webp (in IMAGES)
```

## 3. Pattern

```tsx
// components/three/scene-canvas.tsx
"use client";
import Image, { type StaticImageData } from "next/image";
import { useEffect, useRef } from "react";
import { cn } from "@/lib/utils";

type Props = { poster: StaticImageData; sizes: string; className?: string };

export function SceneCanvas({ poster, sizes, className }: Props) {
  const boxRef = useRef<HTMLDivElement>(null);

  useEffect(() => {
    const box = boxRef.current;
    if (!box) return;
    // New canvas per effect run: Strict Mode runs effects twice,
    // and a canvas can be handed to a worker only once.
    const canvas = document.createElement("canvas");
    if (!("transferControlToOffscreen" in canvas)) return; // poster stays
    const reduced = matchMedia("(prefers-reduced-motion: reduce)").matches;
    if (reduced) return; // poster stays (or: render one frame, no loop)

    canvas.setAttribute("aria-hidden", "true");
    canvas.className =
      "absolute inset-0 size-full opacity-0 transition-opacity data-live:opacity-100";
    box.append(canvas);

    const small = matchMedia(
      "(max-width: 47.99rem), (pointer: coarse)",
    ).matches;
    const size = () => ({
      w: box.clientWidth,
      h: box.clientHeight,
      dpr: Math.min(devicePixelRatio, small ? 1.5 : 2),
    });

    const worker = new Worker(
      new URL("../../lib/three/scene.worker.ts", import.meta.url),
      { type: "module" },
    );
    worker.onmessage = (e: MessageEvent) => {
      if (e.data.type === "ready") canvas.dataset.live = ""; // first frame → fade in
      if (e.data.type === "error") canvas.remove(); // WebGL failed → poster
    };
    const offscreen = canvas.transferControlToOffscreen();
    worker.postMessage({ type: "init", canvas: offscreen, ...size() }, [
      offscreen,
    ]);

    // Loop runs only while on screen and tab visible
    let onScreen = false;
    const sendRunning = () =>
      worker.postMessage({
        type: "running",
        value: onScreen && !document.hidden,
      });
    const io = new IntersectionObserver(([entry]) => {
      onScreen = entry.isIntersecting;
      sendRunning();
    });
    io.observe(box);
    document.addEventListener("visibilitychange", sendRunning);

    const ro = new ResizeObserver(() =>
      worker.postMessage({ type: "resize", ...size() }),
    );
    ro.observe(box);

    const onPointer = (e: PointerEvent) =>
      worker.postMessage({
        type: "pointer",
        x: e.clientX / innerWidth,
        y: e.clientY / innerHeight,
      });
    addEventListener("pointermove", onPointer, { passive: true });

    return () => {
      io.disconnect();
      ro.disconnect();
      document.removeEventListener("visibilitychange", sendRunning);
      removeEventListener("pointermove", onPointer);
      worker.postMessage({ type: "dispose" });
      worker.terminate();
      canvas.remove();
    };
  }, []);

  return (
    <div ref={boxRef} className={cn("relative overflow-hidden", className)}>
      {/* Poster: first paint + fallback. Decorative, the scene adds no content */}
      <Image
        src={poster}
        alt=""
        sizes={sizes}
        className="size-full object-cover"
      />
    </div>
  );
}
```

```ts
// lib/three/scene.worker.ts
import { createScene, type Scene } from "./scene";

let scene: Scene | undefined;

self.onmessage = async (e: MessageEvent) => {
  const m = e.data;
  switch (m.type) {
    case "init":
      try {
        scene = await createScene(m.canvas, m); // renderer, camera, models
        scene.renderOnce();
        self.postMessage({ type: "ready" });
      } catch {
        self.postMessage({ type: "error" });
      }
      break;
    case "running":
      scene?.setRunning(m.value); // starts / stops the rAF loop
      break;
    case "resize":
      scene?.resize(m.w, m.h, m.dpr); // also renders one frame when paused
      break;
    case "pointer":
      scene?.pointer(m.x, m.y);
      break;
    case "dispose":
      scene?.dispose();
      scene = undefined;
      break;
  }
};
```

- Messages = the only link between threads: main sends `init` (canvas + size), `running`, `resize`, `pointer`, `dispose`; worker answers `ready` / `error`. Keep them small, no per-frame data from main.
- `"running"` may arrive before `init` finishes → `scene.ts` keeps the wanted state and starts the loop when ready.
- Poster from `IMAGES` with real `sizes`. Section using it decides `preload` only if the poster is the LCP image (SKILL.md section 4, Images).
- Worker path: relative `new URL("...", import.meta.url)` (aliases inside `new URL` may not resolve). Check Next.js / Turbopack docs for current worker support.
- `scene.ts`: `new WebGLRenderer({ canvas, alpha: true })`, `renderer.setSize(w, h, false)` (no style on OffscreenCanvas), loop with `requestAnimationFrame` (exists in workers) or `renderer.setAnimationLoop`.
- No DOM in worker: no `window`, `document`, `TextureLoader` with `<img>` → use `ImageBitmapLoader`; `GLTFLoader` works.
- Colors / sizes the scene needs come from tokens: read CSS vars on main thread, send in `init`.

## 4. Checklist

- [ ] Scene renders in a worker (`OffscreenCanvas`); canvas created in the effect (Strict Mode: no `InvalidStateError` in dev console)
- [ ] Poster always there: first paint, fallback for no support / WebGL error / reduced motion
- [ ] Canvas not LCP; page text / image paints first
- [ ] Reduced motion → still frame; loop paused off screen / hidden tab
- [ ] DPR capped (2 / 1.5 small + touch), models compressed, sizes listed
- [ ] Everything disposed, worker terminated on unmount
- [ ] Lighthouse performance checked with the scene on (`references/seo.md`)
